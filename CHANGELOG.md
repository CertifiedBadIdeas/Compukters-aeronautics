# Changelog

## 1.0

In development.

- Add a typed `Servo` peripheral for Simulated Swivel Bearings, with signed finite rotation,
  unwrapped multi-turn observation, absolute targets, stopping and measured completion waits.
- Preserve native kinetic power, assembly, Sable constraints and holding coefficients.
- Release digital control on program exit, close, network loss, disassembly and removal.
- Support the six bearing orientations and rotation relative to a moving physical base.
